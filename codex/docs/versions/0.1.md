### Prüfung vor dem Merge

Zwei unabhängige Codex-Prüfungen (`gpt-6.1-sol`, high) fanden zwei korrigierte P2-Befunde:
Capture-only erhält nun Manifest/Galerie unverändert und weist abweichende Geometrie ab; QA wird separat gespeichert.
Die Bogenoptiken sitzen neben Wurfarmen/Sehne auf verbundenen Auslegern, die Flux-Impulsoptik auf höheren Klemmen.
Sichtstrahlen werden gegen die gesamte Baugruppe geprüft. Nachprüfung beider Befunde ohne offene Beanstandung;
50 Tests grün, zusätzliche numerische Nachprüfung von 260 Strahlen an den betroffenen Klassen.
